<div className="sec-eye">Why Acme CLI</div>

<h2 className="sec-h2">Three things you can stop doing today.</h2>

<div className="sec-lead">YAML is a checked baggage problem. Acme CLI replaces three things. A templating language, a state file, and a CI plugin. With one signed binary that knows about all three.</div>

<Callout type="tip" title="Already know terraform?">
  Acme CLI's plan/apply loop is the same shape, but the configuration language
  is type-checked Cue rather than HCL, and state is content-addressed instead
  of timestamp-locked. Migration takes one afternoon for most teams.
</Callout>

</div>

<div className="sec">

<div className="sec-eye">How it works</div>

<h2 className="sec-h2">Four stages. One binary.</h2>

<Steps>
  <Step title="Stage 01 · Author">
    Write your stack as `*.cue` files. The compiler enforces structural type
    safety at write-time. No more `terraform plan` surprises.
  </Step>
  <Step title="Stage 02 · Plan">
    `acme plan` evaluates every change and emits a content-addressed plan
    artifact. Plans are deterministic and review-friendly.
  </Step>
  <Step title="Stage 03 · Apply">
    `acme apply <plan-hash>` is a one-liner. Workers fan out, run side-effects
    in dependency order, and abort on first error.
  </Step>
  <Step title="Stage 04 · Observe">
    Every apply emits a structured event log. Pipe it to your existing
    observability stack. No separate Acme dashboard to operate.
  </Step>
</Steps>

</div>

<div className="sec">

<div className="sec-eye">Quickstart</div>

<h2 className="sec-h2">Deploy in five minutes.</h2>

<div className="sec-lead">If you've got Docker and 5MB of disk, you've got everything you need.</div>

```bash
# 1. Install the binary
curl -sSL https://acme.example/install.sh | sh

# 2. Initialize a stack
acme init my-stack && cd my-stack

# 3. Plan + apply
acme plan
acme apply
```

<Callout type="warn" title="Production checklist">
  For real workloads, set `ACME_STATE_BUCKET` to a versioned S3-compatible
  bucket and rotate it through CI. Never check state into git.
</Callout>

</div>
