`<Tabs>` shows one panel at a time and lets the reader switch between
parallel views of the same content. Each `<Tab>` declares a `label` and any
MDX as children.

### <Chunk id="tabs-langs" importance={0.7} tags={["tabs", "languages"]}>Language picker</Chunk>

The most common use: showing the same example in multiple languages.

<Tabs>
  <Tab label="cURL">
    ```bash
    curl -X POST http://localhost:3000/api/docs/search \
      -H 'content-type: application/json' \
      -d '{"query":"how do chunks work","topK":5}'
    ```
  </Tab>
  <Tab label="JavaScript">
    ```js
    const res = await fetch('/api/docs/search', {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({ query: 'how do chunks work', topK: 5 }),
    });
    const { results } = await res.json();
    ```
  </Tab>
  <Tab label="Python">
    ```py
    import requests
    r = requests.post(
        'http://localhost:3000/api/docs/search',
        json={'query': 'how do chunks work', 'topK': 5},
    )
    results = r.json()['results']
    ```
  </Tab>
</Tabs>

### <Chunk id="tabs-os" importance={0.55} tags={["tabs", "os"]}>OS-specific instructions</Chunk>

<Tabs>

    ```bash
    npm install
    ```
  </Tab>
  <Tab label="Linux (Debian/Ubuntu)">
    ```bash
    sudo apt-get install -y build-essential
    npm install
    ```
  </Tab>
  <Tab label="Windows (WSL recommended)">

### <Chunk id="tabs-when" importance={0.45} tags={["tabs", "guidance"]}>When to use tabs</Chunk>

| Use it for | Skip it for |
| --- | --- |
| Mutually exclusive choices | Sequential steps. Use Steps |
| Same example in N languages | Single canonical example. Just use a code block |
| OS- or runtime-specific docs | Generic instructions. Keep them inline |
