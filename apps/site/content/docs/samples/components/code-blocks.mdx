Standard markdown code fences (` ``` `) render through the framework's
`<CodeBlock>` component. The language hint after the opening fence drives
syntax highlighting and the language label shown in the top-right corner.

### <Chunk id="code-no-lang" importance={0.4} tags={["code", "plain"]}>No language hint</Chunk>

If you skip the language hint, the block still renders. Just without
highlighting and with `text` as the language label.

```
▸ doks ingest
  embedder: voyage (voyage-3-lite, 512d)
  found 88 chunks across docs

```

### <Chunk id="code-when" importance={0.45} tags={["code", "guidance"]}>Authoring tips</Chunk>

- **Always set the language.** It powers both the highlighter and the visible
  label, and improves screen-reader semantics.
- **Keep blocks ≤ 25 lines** when possible. Long blocks hurt mobile reading
  and bloat the chunk for retrieval.
- **Show the smallest reproducible snippet.** Diff-style fragments beat full
  files for retrieval scoring. The chunk text becomes more discriminative.
